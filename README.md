# hiskdk - AIoT 2026 Personal Page

A modern cyberpunk dark glassmorphic personal page featuring a live real-time digital clock, dynamic context-aware greetings, and AIoT 2026 focus highlights.

## 📌 Features

- **Live Real-Time Digital Clock**: Millisecond-accurate clock with live seconds, 12H/24H toggle, full localized calendar date, timezone display, and daily elapsed progress bar.
- **Dynamic Greeting**: Automatically greets the visitor according to local time (Morning, Afternoon, Evening, Night).
- **Aesthetic**: Cyberpunk dark mode with glassmorphic cards (backdrop-filter: blur), glowing neon ambient aura, and interactive theme palettes.
- **AIoT 2026 Focus**: Interactive technical stack tags, chronometer widget, and responsive ambient dashboard.
- **Customizable Profile**: Interactive inline name editor with automatic browser `localStorage` persistence.

## 🚀 Quick Start

Simply open `index.html` in your browser, or run a lightweight local server:

```bash
# Using Python
python -m http.server 8080
```

Visit `http://localhost:8080/` to preview the page.
